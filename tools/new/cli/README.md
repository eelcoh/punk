# @app@

A command-line program in [punk-lang](https://github.com/eelcoh/punk).

```
punk @App@.punk              # run it
punk test @App@.punk         # run its expect tests
punk fmt @App@.punk          # format it
punk check @App@.punk        # check it, without running
```

`AGENTS.md` is for coding agents, and `.claude/skills/` has punk's skills.
